# DevOps & Cloud Learning Space

Không gian học **DevOps & Cloud (AWS-first)** — từ Linux, Docker, CI/CD, AWS, Terraform, Kubernetes đến Observability, SRE và DevSecOps.

- **Đối tượng:** Developer đã có kinh nghiệm, mới với DevOps
- **Mục tiêu:** Sẵn sàng cho vị trí DevOps / SRE
- **Thời lượng:** 28 tuần × ~10h/tuần
- **Chứng chỉ:** AWS SAA · CKA · Terraform Associate (tuỳ chọn)

## Lộ trình

| Phase | Tuần | Nội dung |
|---|---|---|
| 0 — Nền tảng | 1–4 | Linux & Shell · Networking · DevOps mindset & Git |
| 1 — Containers & CI/CD | 5–9 | Docker · GitHub Actions · Checkpoint 1 |
| 2 — AWS Cloud | 10–15 | IAM · VPC/EC2/ALB · RDS/S3/Lambda · Well-Architected · SAA |
| 3 — Infrastructure as Code | 16–18 | Terraform · Ansible & Packer |
| 4 — Kubernetes & GitOps | 19–23 | K8s core · EKS & Helm · Argo CD · CKA |
| 5 — Observability, SRE, DevSecOps | 24–26 | Prometheus/Grafana/OTel · SLO · Supply chain security |
| Capstone | 27–28 | Production-grade platform trên AWS |

👉 Chi tiết đầy đủ: [docs/curriculum.md](docs/curriculum.md)
