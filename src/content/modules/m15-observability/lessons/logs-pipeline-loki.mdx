<Eli5 title="Log tập trung giống như bưu điện gom thư của cả thành phố" emoji="📮">

Hồi M01 bạn đọc log bằng cách **tới tận nhà** (SSH vào server) và mở sổ ra xem (`tail -f`). Với Kubernetes, bạn có 300 pod, pod sinh ra rồi biến mất sau mỗi lần deploy — như một thành phố mà nhà cửa **tự dời đi mỗi ngày**. Tới tận nơi là bất khả thi.

Giải pháp: mỗi nhà chỉ việc **bỏ thư vào hộp thư ở tầng** (in log ra stdout). Một **bưu tá** ở mỗi khu phố (agent DaemonSet như Grafana Alloy, Fluent Bit) đi gom, **dán mã bưu chính** (label: namespace, app, pod) rồi chở về **bưu điện trung tâm** (Loki hoặc CloudWatch Logs). Muốn tìm thư, bạn tra theo mã bưu chính trước, rồi mới lục nội dung.

Chỗ ví von hụt: thư thật mất thì thôi, còn log bị mất khi agent quá tải là chuyện có thật — cần theo dõi cả "bưu tá".

</Eli5>

Log là trụ cột **đắt nhất** và cũng dễ làm sai nhất: quá ít thì không debug được, quá nhiều thì hoá đơn CloudWatch tăng vọt. DevOps cần thiết kế đường ống log sao cho app không phải biết log đi đâu, và đội dev tìm được đúng dòng log trong vài giây.

### Nguyên tắc 12-factor: log là stream

App **chỉ in ra stdout/stderr**, không tự xoay vòng file, không tự gửi lên server log. Việc thu gom là của nền tảng. Nhờ vậy cùng một image chạy được với Loki, CloudWatch hay Datadog.

### Các lựa chọn agent

| Agent | Ghi chú |
|---|---|
| **Grafana Alloy** | Bản phân phối OpenTelemetry Collector của Grafana, thay thế Grafana Agent và **Promtail** (Promtail đã bị deprecate — kiểm tra tài liệu mới nhất) |
| **Fluent Bit** | Nhẹ, viết bằng C, CNCF; AWS dùng trong Container Insights |
| **OpenTelemetry Collector** | Receiver `filelog`; hợp khi muốn gom cả metrics/traces về một agent |
| Fluentd | Nhiều plugin nhưng nặng hơn; đang dần nhường chỗ cho Fluent Bit |

### Loki: đánh index label, không index nội dung

Loki lưu log thành **stream** = một bộ label duy nhất. Chỉ label được index; nội dung nén thành chunk trên object storage (S3). Vì vậy:

- Label nên **ít giá trị**: `cluster`, `namespace`, `app`, `level`. **Không** dùng `user_id`, `trace_id`, `request_id` làm label.
- Mọi truy vấn LogQL bắt đầu bằng stream selector trong ngoặc nhọn.

```text title="LogQL"
# Chọn stream, lọc chuỗi, parse JSON, lọc theo field
{namespace="shop", app="payments"} |= "timeout" | json | level="error"

# Tìm theo trace_id — lọc nội dung, KHÔNG phải label
{namespace="shop"} |= "4bf92f3577b34da6a3ce929d0e0e4736"

# Metric từ log: số dòng lỗi mỗi giây theo app
sum by (app) (rate({namespace="shop"} | json | level="error" [5m]))
```

### Fluent Bit → CloudWatch Logs

```ini title="fluent-bit.conf (rút gọn)"
[INPUT]
    Name              tail
    Path              /var/log/containers/*.log
    multiline.parser  docker, cri
    Tag               kube.*

[FILTER]
    Name              kubernetes
    Match             kube.*
    Merge_Log         On

[OUTPUT]
    Name              cloudwatch_logs
    Match             kube.*
    region            ap-southeast-1
    log_group_name    /eks/shop/application
    log_stream_prefix pod-
    auto_create_group On
```

Trên EKS, cách ít công nhất là bật add-on **Amazon CloudWatch Observability** (Container Insights + Fluent Bit). Quyền ghi log cấp qua **EKS Pod Identity** hoặc IRSA — không gắn access key vào pod.

### Structured log & liên kết trace

```json title="một dòng log tốt"
{"ts":"2026-09-14T09:41:31Z","level":"error","service":"payments","msg":"bank gateway timeout","duration_ms":3002,"trace_id":"4bf92f3577b34da6a3ce929d0e0e4736","span_id":"00f067aa0ba902b7"}
```

Trong Grafana, cấu hình **derived field** cho data source Loki (regex `"trace_id":"(\w+)"`) để biến `trace_id` thành link mở thẳng trace trong Tempo.

### Loki hay CloudWatch?

| | Loki tự host | CloudWatch Logs |
|---|---|---|
| Vận hành | Tự lo scale, S3, compaction | AWS lo |
| Chi phí | Chủ yếu S3 + compute | Theo GB ingest + lưu + GB quét khi query |
| Truy vấn | LogQL, chung Grafana với metrics/traces | Logs Insights, tích hợp AWS |

Giá thay đổi theo region và thời điểm — kiểm tra trang giá mới nhất trước khi quyết định.

<Callout type="cost" title="Log group mặc định lưu vĩnh viễn">

Log group CloudWatch mới tạo có retention **Never expire**. Hai năm sau bạn trả tiền lưu hàng TB log debug không ai đọc. Đặt retention ngay khi tạo (Terraform: `retention_in_days`) và hạ log level production xuống `info`.

</Callout>

<Callout type="mistake" title="Dùng trace_id / user_id làm label Loki">

Mỗi giá trị label mới tạo một stream mới → hàng triệu stream nhỏ, Loki chậm và có thể từ chối ghi. Giữ những field đó trong nội dung JSON và lọc bằng `|=` hoặc `| json`.

</Callout>

<Callout type="warning" title="Đừng log dữ liệu nhạy cảm">

Mật khẩu, token, số thẻ, toàn bộ request body không được vào log — log thường được nhiều người đọc hơn database. Che (redact) ở app hoặc bằng processor của agent.

</Callout>
