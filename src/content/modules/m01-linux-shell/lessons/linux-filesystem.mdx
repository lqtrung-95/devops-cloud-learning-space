## Vì sao DevOps phải biết Linux?

Hơn 90% server trên cloud chạy Linux. Docker container thực chất là tiến trình Linux. Kubernetes node chạy Linux. Pipeline CI/CD chạy trên runner Linux. Nói cách khác: **Linux là mặt đất mà mọi thứ khác xây lên**.

<Technical>

**Linux** là một _kernel_ (nhân hệ điều hành) — phần mềm nói chuyện trực tiếp với phần cứng. Khi người ta nói "Ubuntu", "Debian", "Amazon Linux", "RHEL", đó là các **distribution (distro)**: kernel Linux + bộ công cụ + trình quản lý gói.

| Distro | Hay gặp ở đâu | Quản lý gói |
|---|---|---|
| Ubuntu / Debian | Server phổ biến, Docker image | `apt` |
| Amazon Linux / RHEL / Rocky | AWS EC2, doanh nghiệp | `dnf` / `yum` |
| Alpine | Docker image siêu nhỏ | `apk` |

### Filesystem Hierarchy Standard (FHS)

Linux có **một cây thư mục duy nhất** bắt đầu từ `/` (root directory). Ổ đĩa khác không thành `D:` mà được **mount** (gắn) vào một thư mục trong cây, ví dụ `/mnt/data`.

- `/etc` — cấu hình hệ thống (text file, sửa được bằng editor)
- `/var` — dữ liệu biến đổi: log (`/var/log`), dữ liệu Docker (`/var/lib/docker`)
- `/home/<user>` — thư mục cá nhân, viết tắt là `~`
- `/bin`, `/usr/bin` — chương trình (ls, cp, python3…)
- `/tmp` — file tạm, có thể bị xoá khi reboot
- `/proc` — thư mục "ảo" do kernel tạo ra, chứa thông tin tiến trình và phần cứng

### Đường dẫn tuyệt đối vs tương đối

- **Tuyệt đối** (absolute): bắt đầu bằng `/`, ví dụ `/var/log/syslog` — đúng ở mọi nơi.
- **Tương đối** (relative): tính từ thư mục hiện tại. `.` = ở đây, `..` = thư mục cha.

</Technical>

Một vài lệnh đọc file hay dùng:

```bash
cat /etc/os-release      # in toàn bộ file (file ngắn)
less /var/log/syslog     # đọc từng trang, gõ q để thoát, /từ-khoá để tìm
head -n 20 app.log       # 20 dòng đầu
tail -f app.log          # theo dõi dòng mới được ghi thêm (Ctrl+C để dừng)
```

<Callout type="mistake">
  **`rm -rf` không có thùng rác.** Gõ nhầm `rm -rf / home/trung` (thừa dấu cách) có thể xoá cả hệ thống. Luôn kiểm tra kỹ đường dẫn, và dùng `ls` xem trước những gì sắp xoá.
</Callout>

<Callout type="tip">
  Nhấn **Tab** để tự hoàn thành tên file/thư mục, **Ctrl+R** để tìm lại lệnh đã gõ. Hai phím này tiết kiệm cho bạn hàng giờ mỗi tuần.
</Callout>
