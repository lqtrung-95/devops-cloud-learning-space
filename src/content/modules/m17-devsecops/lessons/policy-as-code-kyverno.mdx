<Technical>

### Kyverno là gì

Kyverno là một **admission controller** cho Kubernetes: mọi request tạo/sửa resource đi qua API server sẽ được Kyverno kiểm tra trước khi được ghi vào etcd. Khác với OPA Gatekeeper (viết policy bằng ngôn ngữ Rego), Kyverno viết policy bằng **YAML thuần**, dễ tiếp cận hơn cho người quen Kubernetes manifest.

### Ba chế độ hoạt động

| Chế độ | Hành vi |
|---|---|
| `Audit` | Ghi nhận vi phạm vào `PolicyReport`, KHÔNG chặn request |
| `Enforce` | Chặn request ngay tại admission, trả lỗi rõ ràng cho `kubectl apply` |
| `mutate` | Tự động sửa resource (thêm label, set giá trị mặc định) trước khi lưu |

Luôn triển khai policy mới ở `Audit` trước, dọn hết vi phạm hiện có, rồi mới chuyển `Enforce` — tránh việc bật policy mới làm sập cả loạt deploy đang chạy tốt.

### Policy 1: bắt buộc resource limits

```yaml title="require-resource-limits.yaml"
apiVersion: kyverno.io/v1
kind: ClusterPolicy
metadata:
  name: require-resource-limits
spec:
  validationFailureAction: Enforce
  rules:
    - name: check-limits
      match:
        any:
          - resources: { kinds: ["Pod"] }
      validate:
        message: "Mỗi container phải khai báo resources.limits.cpu và memory"
        pattern:
          spec:
            containers:
              - resources:
                  limits:
                    cpu: "?*"
                    memory: "?*"
```

### Policy 2: cấm tag `:latest`

```yaml title="disallow-latest-tag.yaml"
apiVersion: kyverno.io/v1
kind: ClusterPolicy
metadata:
  name: disallow-latest-tag
spec:
  validationFailureAction: Enforce
  rules:
    - name: require-image-tag
      match:
        any:
          - resources: { kinds: ["Pod"] }
      validate:
        message: "Không được dùng image tag :latest hoặc thiếu tag — chỉ định version hoặc digest cụ thể"
        pattern:
          spec:
            containers:
              - image: "!*:latest"
```

### Policy 3: cấm privileged, bắt buộc non-root

```yaml title="disallow-privileged-and-root.yaml"
apiVersion: kyverno.io/v1
kind: ClusterPolicy
metadata:
  name: disallow-privileged-and-root
spec:
  validationFailureAction: Enforce
  rules:
    - name: no-privileged
      match:
        any:
          - resources: { kinds: ["Pod"] }
      validate:
        message: "Container không được chạy ở chế độ privileged"
        pattern:
          spec:
            containers:
              - =(securityContext):
                  =(privileged): "false"
    - name: require-run-as-nonroot
      match:
        any:
          - resources: { kinds: ["Pod"] }
      validate:
        message: "Pod phải đặt securityContext.runAsNonRoot: true"
        pattern:
          spec:
            securityContext:
              runAsNonRoot: true
```

### Policy 4: chỉ chấp nhận image đã ký (nối bài trước)

```yaml title="verify-image-signature.yaml"
apiVersion: kyverno.io/v1
kind: ClusterPolicy
metadata:
  name: verify-image-signature
spec:
  validationFailureAction: Enforce
  rules:
    - name: verify-signature
      match:
        any:
          - resources: { kinds: ["Pod"] }
      verifyImages:
        - imageReferences:
            - "registry.example.com/*"
          attestors:
            - entries:
                - keyless:
                    subject: "https://github.com/my-org/checkout/.github/workflows/*"
                    issuer: "https://token.actions.githubusercontent.com"
                    rekor:
                      url: https://rekor.sigstore.dev
```

`verifyImages` chính là bước gọi lại logic `cosign verify` ngay trong admission controller — mọi Pod tạo mới đều tự động được kiểm tra, không ai phải nhớ chạy lệnh tay.

### Xem vi phạm ở chế độ Audit

```bash
kubectl get policyreport -A
kubectl get clusterpolicyreport
```

`PolicyReport`/`ClusterPolicyReport` liệt kê mọi resource đang tồn tại vi phạm policy nào — dùng để dọn dẹp trước khi chuyển Enforce.

</Technical>

<Callout type="mistake" title="Chuyển Enforce ngay không qua Audit">

Bật `Enforce` cho `require-resource-limits` khi 30% Deployment hiện có chưa từng khai báo limits sẽ làm **mọi rollout mới của 30% đó bị chặn ngay lập tức** — kể cả hotfix khẩn cấp. Luôn Audit → dọn dẹp → Enforce.

</Callout>

<Callout type="tip" title="Loại trừ namespace hệ thống">

Thêm `exclude` cho `kube-system`, namespace của chính Kyverno/Prometheus Operator — nhiều workload hệ thống chính đáng chạy privileged hoặc chưa set limits theo thiết kế của nhà cung cấp.

</Callout>
