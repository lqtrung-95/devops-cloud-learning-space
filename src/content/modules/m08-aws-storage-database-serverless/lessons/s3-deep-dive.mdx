<Eli5 title="S3 giống như dịch vụ kho bãi có bảo vệ, phiếu gửi hàng và kho lạnh" emoji="🏭">

Kho S3 có **bảo vệ ở cổng** (Block Public Access, bucket policy): mặc định không ai lạ được vào. Muốn cho một khách gửi đúng một kiện hàng, bạn không đưa họ chìa khoá kho — bạn viết **phiếu gửi hàng có chữ ký**, ghi rõ "kiện số 7f3c, hạn 5 phút". Đó là **pre-signed URL**.

Hàng mới về để ở **kệ trước cửa** (Standard) cho dễ lấy. Hàng lâu không ai hỏi thì chuyển ra **kho phía sau** (Standard-IA), rồi **kho lạnh ngoại thành** (Glacier) — thuê rẻ nhưng muốn lấy phải đặt lịch. Người quản lý kho làm việc này tự động theo **lifecycle rule**.

Còn **versioning** giống việc kho giữ lại cả thùng cũ khi bạn gửi thùng mới cùng mã — lỡ tay ghi đè hay xoá vẫn lấy lại được.

</Eli5>

Với DevOps, S3 có mặt ở khắp nơi: artifact build, Terraform state, backup database, log ALB/CloudTrail, file người dùng, static website. Một bucket public nhầm là sự cố bảo mật kinh điển; một bucket không có lifecycle là hoá đơn tăng mãi.

<Technical>

### Bảo mật bucket: nhiều lớp cùng quyết định

- **Block Public Access (BPA)**: công tắc tổng ở cấp account và bucket. Bucket mới mặc định đã bật BPA và tắt ACL (Object Ownership = bucket owner enforced). Giữ nguyên trừ khi thật sự cần public.
- **IAM policy**: gắn vào user/role — "role này được làm gì".
- **Bucket policy**: gắn vào bucket — "ai được làm gì với bucket này", dùng để cho account khác, CloudFront (OAC) hoặc bắt buộc HTTPS.
- Explicit **Deny** luôn thắng (như logic đánh giá policy ở M06).

```json title="bucket-policy.json — chỉ cho truy cập qua HTTPS"
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Sid": "DenyInsecureTransport",
      "Effect": "Deny",
      "Principal": "*",
      "Action": "s3:*",
      "Resource": ["arn:aws:s3:::shop-uploads-123456789012", "arn:aws:s3:::shop-uploads-123456789012/*"],
      "Condition": { "Bool": { "aws:SecureTransport": "false" } }
    }
  ]
}
```

### Pre-signed URL

- Tạo bằng SDK hoặc CLI, ký bằng credentials của người tạo; người dùng URL có **đúng quyền của người ký**, cho đúng object/thao tác, tới khi hết hạn.
- Ký bằng credentials tạm (IAM role) thì URL cũng hết hiệu lực khi session của role hết hạn, dù `expires` dài hơn.
- `aws s3 presign` trong CLI chỉ tạo URL **download (GET)**. URL upload (`PUT` hoặc presigned POST) tạo bằng SDK, ví dụ boto3 `generate_presigned_url("put_object", ...)`.
- Trình duyệt upload trực tiếp cần cấu hình **CORS** trên bucket.

### Storage classes

| Class | Dùng khi | Lưu ý |
|---|---|---|
| Standard | Truy cập thường xuyên | Không phí truy xuất |
| Intelligent-Tiering | Không đoán được tần suất | Tự chuyển tầng, có phí giám sát nhỏ/object |
| Standard-IA / One Zone-IA | Ít truy cập nhưng cần ngay | Tối thiểu 30 ngày, phí/GB khi lấy; One Zone chỉ 1 AZ |
| Glacier Instant Retrieval | Lưu trữ, vài lần/quý, cần mili-giây | Tối thiểu 90 ngày |
| Glacier Flexible Retrieval | Lưu trữ, chờ phút–giờ được | Phải restore trước khi đọc; tối thiểu 90 ngày |
| Glacier Deep Archive | Lưu trữ tuân thủ nhiều năm | Rẻ nhất, restore tính bằng giờ; tối thiểu 180 ngày |

### Lifecycle, versioning, static website

```json title="lifecycle.json"
{
  "Rules": [
    {
      "ID": "uploads-tiering",
      "Filter": { "Prefix": "uploads/" },
      "Status": "Enabled",
      "Transitions": [{ "Days": 30, "StorageClass": "STANDARD_IA" }],
      "NoncurrentVersionExpiration": { "NoncurrentDays": 90 },
      "AbortIncompleteMultipartUpload": { "DaysAfterInitiation": 7 }
    }
  ]
}
```

- **Versioning** bật rồi chỉ có thể *suspend*, không tắt hẳn. Xoá object tạo *delete marker*; bản cũ vẫn tính tiền → cần `NoncurrentVersionExpiration`.
- **Static website hosting** cho endpoint HTTP công khai. Production nên dùng **CloudFront + Origin Access Control** trỏ vào bucket private để có HTTPS, cache và không mở public bucket.

</Technical>

<Callout type="mistake">

**Tắt Block Public Access để "cho frontend upload được".** Kết quả: ai cũng có thể ghi/đọc bucket. Hãy dùng pre-signed URL (upload) và CloudFront + OAC (phục vụ file) — bucket vẫn private.

</Callout>

<Callout type="cost">

Lifecycle chuyển **hàng triệu object nhỏ** sang IA/Glacier có thể **đắt hơn** giữ nguyên: mỗi transition tính phí request, IA tính tối thiểu 128 KB/object, Glacier cộng thêm metadata overhead. Upload multipart dở dang cũng âm thầm tính tiền — luôn thêm `AbortIncompleteMultipartUpload`.

</Callout>

<Callout type="warning">

Pre-signed URL là **bearer token**: ai có link là dùng được tới khi hết hạn. Đặt hạn ngắn, key do server quyết định, và đừng log nguyên URL.

</Callout>
