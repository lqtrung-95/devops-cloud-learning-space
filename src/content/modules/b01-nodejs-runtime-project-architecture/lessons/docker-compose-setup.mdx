### Dockerfile multi-stage tối giản

Multi-stage giúp image cuối cùng không "cõng" theo compiler TypeScript và devDependencies — sẽ tối ưu sâu hơn ở B17, nhưng bản tối giản này đã tách đúng 2 stage:

```dockerfile title="Dockerfile"
# Stage 1: build — có đủ devDependencies để biên dịch TypeScript
FROM node:22-slim AS builder
WORKDIR /app
COPY package*.json ./
RUN npm ci
COPY . .
RUN npm run build

# Stage 2: runtime — chỉ mang theo dist/ và dependencies production
FROM node:22-slim
WORKDIR /app
COPY package*.json ./
RUN npm ci --omit=dev
COPY --from=builder /app/dist ./dist
EXPOSE 3000
CMD ["node", "dist/app.js"]
```

`COPY --from=builder` chỉ lấy đúng thư mục `dist/` từ stage trước — source TypeScript, `node_modules` dev, test file... đều không lọt vào image cuối.

### docker-compose.yml — 3 service cố định

Spec này **dùng chung cho cả course**, sao chép chính xác — không đổi tên biến, port hay service:

```yaml title="docker-compose.yml"
services:
  api:
    build: .
    ports:
      - "3000:3000"
    environment:
      DATABASE_URL: postgres://taskflow:taskflow@postgres:5432/taskflow
      REDIS_URL: redis://redis:6379
    depends_on:
      postgres:
        condition: service_healthy
      redis:
        condition: service_started

  postgres:
    image: postgres:17
    environment:
      POSTGRES_USER: taskflow
      POSTGRES_PASSWORD: taskflow
      POSTGRES_DB: taskflow
    ports:
      - "5434:5432"
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U taskflow"]
      interval: 5s
      timeout: 5s
      retries: 5

  redis:
    image: redis:7
    ports:
      - "6380:6379"
```

### Cổng container vs cổng host

`"5434:5432"` nghĩa là `host:container`. **Bên trong** network của Compose, `api` luôn gọi `postgres` qua cổng container gốc — `5432` — vì đó là cổng Postgres thật sự lắng nghe. `5434` chỉ tồn tại để bạn `psql` từ máy host vào container. Cùng logic cho Redis: container luôn là `6379`, host là `6380`.

Vì vậy `DATABASE_URL` trong biến môi trường của `api` luôn dùng `postgres:5432` (tên service + cổng container), không phải `localhost:5434`.

<Callout type="mistake">
  Khai báo `DATABASE_URL` với `localhost:5434` thay vì `postgres:5432`. Bên trong container `api`, `localhost` là chính nó, không phải máy host — và cổng đúng để gọi service khác trong cùng network Compose luôn là cổng container gốc.
</Callout>

<Callout type="warning" title="taskflow/taskflow chỉ dùng cho dev">
  Mật khẩu Postgres `taskflow` là quy ước **chỉ dành cho môi trường lab local** — không bao giờ dùng lại giá trị này (hay hard-code bất kỳ secret nào) khi triển khai thật. Quản lý secret đúng cách sẽ học ở B15.
</Callout>
